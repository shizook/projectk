# Kompas Corner Web Platform 📰

Selamat datang di repositori resmi **Kompas Corner**. Repositori ini memuat kode sumber (*source code*) untuk platform website Kompas Corner yang berfungsi sebagai media publikasi digital untuk merilis artikel, berita, opini, dan karya jurnalistik mahasiswa.

Platform ini dirancang untuk memberikan pengalaman membaca yang responsif, cepat, dan nyaman bagi pengguna, serta menyediakan sistem manajemen konten yang efisien bagi tim redaksi.

---

## ✨ Fitur Utama

*   **Penerbitan Artikel:** Sistem rilis artikel multimedia (teks, gambar, video) yang dinamis dan terstruktur.
*   **Kategorisasi Konten:** Pengelompokan artikel berdasarkan topik (misal: *Campus News, Opini, Feature, Event*, dll).
*   **Desain Responsif:** Optimasi tampilan yang nyaman diakses melalui perangkat *mobile*, tablet, maupun desktop.
*   **Fitur Pencarian & Filter:** Memudahkan pembaca menemukan artikel lama atau topik spesifik dengan cepat.
*   **Optimasi SEO & Performa:** Memastikan artikel mudah ditemukan di mesin pencari dan pemuatan halaman yang cepat.

## 👥 Kontribusi

Kami menerima kontribusi untuk pengembangan website ini. Jika Anda ingin memperbaiki *bug* atau menambahkan fitur baru:
1. *Fork* repositori ini.
2. Buat *branch* baru untuk fitur Anda (`git checkout -b fitur-baru`).
3. Lakukan *commit* pada perubahan Anda (`git commit -m 'Menambahkan fitur baru'`).
4. *Push* ke *branch* tersebut (`git push origin fitur-baru`).
5. Buat *Pull Request*.
